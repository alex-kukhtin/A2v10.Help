Ім'я Тип Опис
Cells TableCellCollection Властивість вмісту. Клітинки рядка — див. TableCell.
Властивості базового елементу

Увага! З властивостей базового елементу на рядку діє тільки If. Оформлення — Bold, Align, Border, Background — рядок приймає без помилки, але на друк воно не потрапляє. Задавайте його на клітинках або візьміть готове оформлення таблиці: у стилі Details підвал уже напівжирний, а шапка — з сірим тлом.

Зверніть увагу! Властивість If на рядку тіла обчислюється для кожного елемента колекції окремо, тому рядки можна приховувати вибірково: <TableRow If="{Bind !Void}">.
