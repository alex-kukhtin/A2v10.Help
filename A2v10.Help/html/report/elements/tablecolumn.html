Елемент TableColumn

Всі елементи

Колонка таблиці. Задає тільки ширину — все інше описується на клітинках.

Властивості

Ім'я Тип Опис
Width Length Ширина колонки. Стала (80pt, 30mm) або частка вільного місця (1fr). Якщо колонок не оголошено взагалі, таблиця отримує одну колонку на всю ширину.

Короткий запис

Оголошувати кожну колонку окремим елементом зазвичай не потрібно: список ширин через кому перетворюється на колонки автоматично.

Зверніть увагу! Частки (fr) ділять між собою те, що залишилося після сталих колонок. Якщо сталих ширин разом більше, ніж ширина сторінки, документ не збудується — рушій повідомить про суперечливі розміри.
