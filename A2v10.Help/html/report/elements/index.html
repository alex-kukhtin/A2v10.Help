Елементи

Звіти Xaml

Елементи шаблону, написаного руками. Вміст сторінки — це послідовність елементів, які друкуються один за одним і переносяться на наступну сторінку самі.

  • Page — сторінка, корінь шаблону.
  • Column — вертикальна послідовність елементів.
  • Table — таблиця, з шапкою, тілом і підвалом.
  • TableRow — рядок таблиці.
  • TableCell — клітинка таблиці.
  • TableColumn — колонка таблиці (ширина).
  • Text — текстовий абзац і його частини.
  • List — перелік з маркерами.
  • Inlined — елементи поруч, у рядок.
  • Line — горизонтальна лінія.
  • Image — зображення.
  • QrCode — QR-код.
  • Barcode — штрихкод EAN.
  • Checkbox — прапорець.

Спільні для всіх властивості — оформлення, відступи, умова відображення — описані окремо: Базовий елемент.
