Елемент QrCode

Всі елементи

QR-код зі значення. Значення перетворюється на рядок і кодується під час друку.

Властивість вмісту: Value

Властивості

Ім'я Тип Опис
Value Object Властивість вмісту: сталий рядок або прив'язка.
Size Length Сторона квадрата. Якщо не вказано, код займає доступне місце.
Властивості базового елементу

Зверніть увагу! У робочій книзі окремого елемента нема — там QR-код друкує клітинка, якщо її вираз повертає qrCode(...): {(qrCode(Document.Number))}.
