Елемент Barcode

Всі елементи

Лінійний штрихкод стандарту EAN.

Властивість вмісту: Value

Властивості

Ім'я Тип Опис
Value Object Властивість вмісту: код, сталий або з моделі.
Type BarcodeType EAN13 (за замовчуванням) або EAN8.
Width Length Ширина. Код розтягується на неї цілком.
Height Int32 Висота смуг. Число, не Length.
PrintDigits Boolean Чи друкувати цифри під смугами. За замовчуванням True.
Color String Колір смуг (властивість базового елементу).
Властивості базового елементу

Увага! Код — це тільки цифри: 12 або 13 для EAN13, 7 або 8 для EAN8. Коротший варіант означає, що контрольну цифру дорахує сам рушій; довший — що вона вже є і буде перевірена. Інша довжина або невірна контрольна цифра зупиняють друк з повідомленням. Інші стандарти штрихкодів не підтримуються.
