Елемент List

Всі елементи

Перелік: послідовність елементів, у кожного з яких є маркер і вміст. Як і таблиця, вміє повторюватися за колекцією.

Властивість вмісту: Items

Властивості

Ім'я Тип Опис
ItemsSource Array Тільки прив'язка. Колекція, за якою повторюються елементи переліку. Всередині вирази читаються від елемента колекції.
Items ListItemCollection Властивість вмісту. Елементи переліку.
Spacing Single Проміжок між маркером і вмістом, у пунктах.
Властивості базового елементу

ListItem

Властивість вмісту: Content

Ім'я Тип Опис
Content Object Властивість вмісту: текст, прив'язка або вкладений елемент.
Bullet Object Маркер ліворуч від вмісту: сталий текст або прив'язка (наприклад, номер рядка).
