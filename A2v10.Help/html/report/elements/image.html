Елемент Image

Всі елементи

Зображення: логотип, підпис, печатка. Джерело — байти з моделі або файл програми; растр і SVG розрізняються за вмістом, а не за розширенням. Подробиці — Картинки і водяний знак.

Властивості

Ім'я Тип Опис
Source Object Зображення: байти з моделі (прив'язка) або ім'я файлу.
FileName String Друге написання того самого: приймає і ім'я файлу, і байти. Залишене для сумісності зі старими бланками.
Width Length Ширина зображення.
Height Length Висота зображення.
Властивості базового елементу

Зверніть увагу! Якщо значення порожнє, елемент просто нічого не малює — порожньої рамки на його місці не залишається.
