Елемент Page

Всі елементи

Корінь шаблону звіту. Задає розмір і орієнтацію сторінки, шрифт за замовчуванням, колонтитули і водяний знак.

Властивість вмісту: Columns

Властивості

Ім'я Тип Опис
Columns ColumnCollection Властивість вмісту. Колонки сторінки — див. Column.
Header Column Верхній колонтитул: друкується на кожній сторінці.
Footer Column Нижній колонтитул: друкується на кожній сторінці.
Orientation PageOrientation Орієнтація: Portrait (за замовчуванням) або Landscape. Розмір сторінки — A4.
FontFamily String Шрифт за замовчуванням для всього документа. Якщо не вказано — Verdana.
Title String Заголовок документа (потрапляє у властивості PDF-файлу). Підтримує підстановку значень з моделі: Title="Рахунок {Document.No}".
Code String Javascript, який виконується один раз перед побудовою документа. Оголошені тут функції доступні у виразах. Див. Вирази і прив'язки.
Watermark String Водяний знак: ім'я файлу або, через прив'язку, байти з моделі. Малюється під вмістом на кожній сторінці. Див. Картинки і водяний знак.
Властивості базового елементу

Поля сторінки і розмір шрифту

Поля сторінки задаються властивістю Margin базового елементу, розмір шрифту — властивістю FontSize. Якщо їх не вказано, беруться значення за замовчуванням: поля 20mm зверху і знизу, 10mm ліворуч і праворуч, шрифт 9 пунктів.
