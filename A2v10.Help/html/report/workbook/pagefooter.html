Робоча книга

Нижній колонтитул сторінки — той, що задається в Excel у параметрах сторінки. Друкується на кожній сторінці, по центру, під вмістом.

Властивості

Ім'я Тип Опис
Center String Текст колонтитула по центру.
Left String Ліва частина.
Right String Права частина.

Увага! Насправді працює тільки Center: конвертер переносить з книги лише центральну частину колонтитула, і друкується теж тільки вона. Ліву і праву частини в Excel задавати можна, але в звіт вони не потраплять.

Номер сторінки

Коди Excel перетворюються на службові позначки, які підставляються під час друку:

В Excel У шаблоні Що друкується
&P &(Page) Номер поточної сторінки.
&N &(Pages) Загальна кількість сторінок.

Тобто колонтитул &C&P з &N, набраний в Excel, надрукується як «1 з 3».

Зверніть увагу! Це стосується колонтитула сторінки. Не плутайте з діапазоном Footer: той складається зі звичайних клітинок книги, друкується теж на кожній сторінці, але вміст в ньому — будь-який, з виразами і оформленням.
