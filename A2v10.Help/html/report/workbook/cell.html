Cell

Робоча книга

Клітинка книги. Зберігається під своєю адресою ("A1") і майже завжди створюється конвертером з клітинки Excel — тобто пишеться не тут, а в самій книзі.

Властивості

Ім'я Тип Опис
Value String Вміст клітинки: текст, в якому у фігурних дужках підставляються значення з моделі. Див. Вирази і прив'язки.
ColSpan UInt32 Скільки колонок займає клітинка (з об'єднаних клітинок Excel).
RowSpan UInt32 Скільки рядків займає клітинка.
Style String Посилання на набір оформлення книги ("S30").
Format String Формат значення. Зазвичай приїжджає з числового формату клітинки Excel через оформлення, тому окремо його вказують рідко.
DataType DataType Тип значення: String, Number, Currency, Date, Time, DateTime. Якщо не вказано, визначається за самим значенням.
Властивості базового елементу

Що можна написати в клітинці

Текст і підстановки змішуються вільно; формат пишеться після двокрапки. Якщо значення виявилося байтами, клітинка малює картинку — так у бланк потрапляє логотип (Картинки і водяний знак).

Зверніть увагу! Формат клітинки, заданий в Excel, переноситься разом з оформленням. Тому суму зазвичай досить відформатувати в самій книзі, а в тексті написати просто {Sum}.
