Робоча книга

Діапазон — це кілька рядків книги, які мають особливе призначення: повторюються для кожного елемента колекції, друкуються на кожній сторінці або служать шапкою довгої таблиці. Задається в Excel іменованим діапазоном з цілих рядків.

Властивості

Ім'я Тип Опис
Value String Ім'я діапазону у фігурних дужках — для повторюваних це вираз колекції.
Start UInt32 Номер першого рядка, включно.
End UInt32 Номер останнього рядка, включно.

Як назвати діапазон в Excel

Виділіть цілі рядки (саме рядки, не клітинки) і дайте виділенню ім'я. Excel не дозволяє крапку в іменах, тому шлях пишеться через підкреслення — конвертер перетворить його на крапку:

Ім'я в Excel Що означає
Document_Rows Стає {Document.Rows}: рядки діапазону повторюються для кожного елемента колекції, і всередині них вирази читаються від цього елемента ({Item.Name}, {Sum}).
Header Рядки друкуються на початку кожної сторінки.
Footer Рядки друкуються в кінці кожної сторінки.
TableHeader Шапка довгої таблиці: повторюється на кожній сторінці, де таблиця продовжується. Саме це, а не Header, потрібне для «шапки таблиці на кожному аркуші».
TableFooter Підсумкові рядки таблиці: друкуються один раз, після всіх рядків.
Fit Виняток: іменує не рядки, а одну колонку. Ця колонка розтягується на все вільне місце по ширині сторінки, решта лишаються заданої ширини.

Увага! Діапазон має бути з цілих рядків (в Excel посилання виглядає як $10:$10). Іменований діапазон з клітинок конвертер за діапазон не вважає і мовчки пропускає — крім єдиного випадку Fit, який навпаки має бути з цілої колонки.

Вкладені діапазони

Діапазон, що починається всередині іншого, вважається вкладеним: для кожного елемента зовнішньої колекції він проходить свою, взяту вже від цього елемента. Так друкуються, наприклад, серії всередині рядка накладної.

Зверніть увагу! Глибина вкладеності — два рівні. Третій діапазон всередині другого не обробляється.
