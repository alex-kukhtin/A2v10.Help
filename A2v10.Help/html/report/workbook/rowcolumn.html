Row і Column

Робоча книга

Розміри рядків і колонок книги. Обидва зберігаються тільки для тих, де розмір відрізняється від типового, — решта беруть значення за замовчуванням з Workbook.

Row

Ім'я Тип Опис
Height Single Висота рядка в пунктах.

Рядки зберігаються за номером: "Rows": { "1": { "Height": 31.5 } }

Column

Ім'я Тип Опис
Width Single Ширина колонки в пунктах. Від'ємне значення означає, що колонка розтягується на вільне місце — так конвертер позначає колонку з іменем Fit.

Колонки зберігаються за літерою: "Columns": { "A": { "Width": 21.75 } }

Зверніть увагу! Ширина колонки в Excel рахується в символах шрифту, а не в пунктах, і конвертер її перераховує. Тому в шаблоні числа не збігаються з тим, що показує Excel, — це нормально.
