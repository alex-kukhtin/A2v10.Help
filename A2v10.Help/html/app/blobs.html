Файли (blobs)

Тільки NET.Core Об'єкт blobs оголошує, куди в цій кінцевій точці можна завантажити файл. Детальніше про роботу з файлами та зображеннями...

Ключ — ім'я поля кореневого об'єкта моделі: при "model": "Agent" ключ Logo означає поле Agent.Logo. Регістр не має значення, прийнято писати PascalCase — так само, як у SQL і XAML. При збереженні моделі платформа перевіряє посилання в цьому полі (детальніше).

У кінцевій точці з requireBase ключ — просто ім'я, за яким завантажуються вкладення ($uploadBlob('/attachment/upload', null, owner)), полем моделі воно не є.

Права на завантаження — ролі кінцевої точки. Кінцева точка з розділом blobs не може мати власного джерела даних (source).

Властивості об'єкта

Ім'я Тип Опис
accept string Не обов'язково. Дозволені MIME-типи через кому, допускається image/*. Не вказано — будь-який тип. Для зображень (PNG, JPEG, GIF, WebP) і PDF тип визначається за вмістом файлу, для решти — за розширенням імені. Те, що повідомив браузер, не враховується.
maxSize number Не обов'язково. Найбільший розмір файлу, КБ. Не вказано — без обмеження.

Обидва обмеження перевіряє сервер. Файл, що їх порушує, не зберігається, а користувач бачить повідомлення про помилку.
