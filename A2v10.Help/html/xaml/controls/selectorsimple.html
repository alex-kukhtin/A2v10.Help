Елемент SelectorSimple

Всі елементи керування

Являє собою спрощений селектор.

Це скорочений запис для звичайного елемента Selector. Замість того, щоб вручну задавати команду отримання даних, посилання на діалог вибору та властивість відображення, достатньо вказати одну властивість Url - решту SelectorSimple сформує сам за угодою про імена.

Наслідує: Selector : ValuedControl : Control : UIElement : UIElementBase

Властивості

Ім'я Тип Опис
Url String URL кінцевої точки. Ця точка обов'язково повинна містити діалог browse та команду fetch - саме їх SelectorSimple викликає за замовчуванням.
Data Object Завжди прив'язка - Bind. Додаткові параметри для вибору.
Folder Boolean Якщо true, замість fetch і browse викликаються fetchfolder і browsefolder. Використовується для вибору з ієрархічних довідників.
Властивості базового елементу

Умовчання

За вказаним Url SelectorSimple формує решту властивостей базового Selector самостійно:

  • команда отримання даних - Url + '/fetch';
  • діалог вибору - Url + '/browse', з іконкою пошуку;
  • властивість відображення (DisplayProperty) - Name;
  • значення (Value) передається в діалог вибору як аргумент.

Зверніть увагу! Якщо в елементі задано властивість Data, вона буде використовуватися в якості параметрів, як для виклику діалогу вибору (browse), так і для отримання даних з сервера (fetch).
Фактично Data просто дублюється в FetchData базового селектора.
