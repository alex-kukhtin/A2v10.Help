Елемент BlobImage

Всі елементи керування

Тільки NET.Core Зображення в полі запису: показує його, завантажує нове і очищає поле.

Детальніше про роботу з файлами та зображеннями...

Наслідує: UIElementBase

Властивості

Ім'я Тип Опис
Url String Кінцева точка — папка, де лежить model.json з розділом blobs. Ім'я ключа в blobs сюди не пишеться: воно береться з імені поля у Value.
Value Bind Обов'язково, завжди прив'язка. Поле кореневого об'єкта моделі <model>.<Key>, наприклад Agent.Logo. Елемент записує в нього результат завантаження.
Width Length Ширина зображення.
Height Length Висота зображення.
Властивості базового елементу

Увага! Без прив'язки Value вид не завантажиться і система повідомить про помилку розмітки.

Приклад

Відповідний /catalog/agentblob/model.json містить "model": "Agent" і "blobs": { "Logo": {...} }.

Особливості

  • Пусте поле показує область вибору файлу. Після завантаження в поле записуються Id, Token, а також Name і Mime, якщо вони є в об'єкті. Модель стає зміненою, як після редагування будь-якого поля.
  • Кнопка ✕ очищає поле ($empty()).
  • У запис файл потрапляє тільки при збереженні моделі. Працює і для нового запису.
  • Найчастіше задається тільки одна з властивостей Width або Height. Тоді зображення зберігає пропорції.
