Елемент TextView

Всі елементи керування

Тільки NET.Core та Layout: Tabbed. Показує текст, написаний у TextEditor: переходи рядків, жирний шрифт, зображення. Посилання http(s):// відкриваються в новій вкладці, зображення - посилання на оригінал. Тільки показує, нічого не змінює.

Наслідує: UIElementBase

Властивості

Ім'я Тип Опис
Value Bind Обов'язково, завжди прив'язка. Текст для показу.
Delegates Object Прив'язка до того самого об'єкта функцій, що й у TextEditor. Використовується тільки ImageUrl: без неї зображення показуються текстом.
Властивості базового елементу

Приклад

Список коментарів: кожен показується текстом, а за кнопкою редагується в TextEditor.
