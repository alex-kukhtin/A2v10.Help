Елемент PdfReportViewer

Всі елементи керування

Тільки NET.Core Показує готовий звіт прямо на формі. Звіт будується на сервері і відображається вбудованим засобом перегляду PDF самого браузера.

Наслідує: UIElementBase

Властивості

Ім'я Тип Опис
Url String Обов'язкова. Шлях до папки кінцевої точки — тієї, де лежить model.json з розділом reports.
Report String Обов'язкова. Ім'я звіту, ключ у розділі reports.
Argument Object Зазвичай прив'язка. Об'єкт, з якого береться ідентифікатор ($id) для вибірки даних звіту.
Height Length Висота області перегляду.
Властивості базового елементу

Увага! Url і Report обов'язкові: якщо якогось з них нема, вид не завантажиться і система повідомить про помилку розмітки.

Приклад

Кінцева точка, шаблон звіту і кнопки друку поруч з переглядачем — у розділі Показ і друк на формі.
