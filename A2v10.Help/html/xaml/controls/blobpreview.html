Елемент BlobPreview

Всі елементи керування

Тільки NET.Core Перегляд файлу: зображення показує, PDF відкриває вбудованим засобом перегляду браузера, для решти файлів показує ім'я посиланням — клік завантажує файл. Тільки показує, нічого не змінює.

Детальніше про роботу з файлами та зображеннями...

Наслідує: UIElementBase

Властивості

Ім'я Тип Опис
Value Bind Обов'язково, завжди прив'язка. Об'єкт файлу з полями Id, Token, Name, Mime.
Width Length Ширина області перегляду.
Height Length Висота області перегляду.
Властивості базового елементу

Url у елемента немає: файл читається за власним Id і токеном.
