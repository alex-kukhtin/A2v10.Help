Елемент TextEditor

Всі елементи керування

Тільки NET.Core та Layout: Tabbed. Редактор тексту з жирним шрифтом і зображеннями: опис задачі, коментар. Зображення вставляються з буфера обміну або перетягуванням і зберігаються як вкладення запису. Показати текст без редагування - елемент TextView.

Наслідує: UIElementBase

Властивості

Ім'я Тип Опис
Value Bind Обов'язково, завжди прив'язка. Рядкова властивість, в яку редактор записує текст.
Placeholder String Текст-підказка в пустому редакторі.
Disabled Boolean Заборонити редагування. Модель тільки для читання вимикає редактор сама, як і будь-який елемент керування.
Delegates Object Прив'язка до об'єкта з функціями UploadImage, ImageUrl, Submit. Див. нижче.
Властивості базового елементу

Увага! Без прив'язки Value вид не завантажиться і система повідомить про помилку розмітки.

Формат тексту

У властивість записується текст з трьома елементами розмітки:

  • перехід на новий рядок - \n;
  • жирний шрифт - **текст** (Ctrl+B);
  • зображення - ![ім'я](адреса), адресу повертає UploadImage.

Інших елементів немає: Ctrl+I і Ctrl+U не діють, вставлений HTML потрапляє в текст як звичайний текст. Посилання http(s):// - це текст: редактор їх підсвічує, Ctrl+клік (⌘+клік) відкриває. TextView робить їх клікабельними. Для колонки в базі даних достатньо nvarchar(max).

Функції Delegates

Об'єкт функцій створюється один раз у шаблоні і повертається властивістю моделі за посиланням. Редактор викликає функції так само, як функції шаблону: this - модель сторінки. Немає функції - немає і можливості.

  • UploadImage(file: File): Promise<string | null> - завантажує вставлене зображення (PNG, JPEG, GIF, WebP). Повертає рядок, який буде записано в текст як адреса зображення, або null - тоді зображення прибирається. Без цієї функції зображення не вставляються.
  • ImageUrl(src: string): string | null - повертає адресу, за якою браузер покаже зображення з адресою src з тексту, або null - тоді воно залишається текстом. Викликається під час відображення, тому має лише читати модель. Без цієї функції зображення показуються текстом.
  • Submit() - викликається клавішами Ctrl+Enter (⌘+Enter). Наприклад, надіслати коментар.

Зображення як вкладення

Зображення - це вкладення власника тексту, з моменту вставки, а не збереження тексту. У тексті зберігається адреса без токена, наприклад _blob/1234: токен залежить від користувача, і адреса з токеном відкрилася б тільки в автора. Кожен читач отримує власну адресу з ImageUrl, яка шукає файл серед вкладень у моделі.

Приклад: задача з описом і коментарями, кінцева точка /task, вкладення - через кінцеву точку /attachment з прикладу вкладень, base = /task.

Процедура Load

Разом із задачею завантажуються її вкладення з токенами. Токен видається тільки для вкладень задачі, тому чужий Id, вписаний у текст вручну, залишиться текстом.

Шаблон

require('std:url').blobUrl(blob) повертає адресу файлу для об'єкта файлу моделі (Id і Token), для пустого посилання - undefined. Методи $ensureSaved і $uploadBlobFile описані в контролері.

Особливості

  • Поки зображення завантажується, воно напівпрозоре. Стану «завантажується» редактор не повідомляє: проміс UploadImage належить шаблону, тому шаблон сам знає, що завантаження триває, і може на цей час заборонити свої кнопки.
  • Зображення, видалене з тексту, залишається вкладенням запису.
  • Вкладення, видалене зі списку, але згадане в тексті, показується текстом ![ім'я](_blob/…).
