Елемент TreeViewItem

Всі елементи керування

Являє собою один елемент ієрархічного переліку (дерева) TreeView.

Зверніть увагу, що елемент використовується для роботи з ієрархічними джерелами даних.

Наслідує: UIElement : UIElementBase

Властивість вмісту: Label

Властивості

Ім'я Тип Опис
ItemsSource Array Завжди прив'язка (Bind). Джерело даних для отримання дочірніх елементів.
Label String Властивість вмісту. Текст елементу.
Icon Icon Іконка, яка буде відображатися перед вмістом. Якщо іконка не визначена, то буде відображатися іконка, яка визначена у властивостях IconFolder (для папки) або IconItem (для елементу) батьківського елементу TreeView.
IsFolder2 Boolean? Завжди прив'язка. Чи є елемент папкою: у папки є стрілка розгортання, а клік її розгортає замість виділення (якщо в TreeView не встановлено FolderSelect). Потрібна для динамічних дерев, де папка ще не має завантажених дочірніх елементів. Без неї папкою вважається елемент з $hasChildren або з непорожнім ItemsSource; $hasChildren має перевагу і над цією властивістю.
IsGroup Boolean? Завжди прив'язка. Чи починає елемент групу. Додає елементу css-клас group; у стилі SideBarMenu елемента TreeView над ним малюється роздільник. На те, чи є елемент папкою, не впливає.
IsFolder Boolean? Інше ім'я IsGroup - не плутати з IsFolder2.
InitialExpand Boolean Розгортати папки при створенні і після оновлення даних.
