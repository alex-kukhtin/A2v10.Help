Елемент ColorComboBox

Всі елементи керування

Являє собою спадний список, елементи якого відображаються кольоровими мітками.

Наслідує: ValuedControl : Control : UIElement : UIElementBase

Властивість вмісту: Children

Властивості

Ім'я Тип Опис
ItemsSource Array Завжди прив'язка - Bind. Джерело даних для відображення в списку.
Children List<ColorComboBoxItem> Властивість вмісту. Рівно один елемент ColorComboBoxItem, який зв'язує властивості елементів масиву з текстом, значенням і кольором мітки (див. нижче).
Align TextAlign Вирівнювання тексту.
DropUp Boolean Розкривати список вгору.
Size ControlSize Розмір елементу. Можливі значення:
  • Default - (за замовчуванням) список звичайного розміру.
  • Large - збільшений розмір переліку.
Властивості базового елементу

Властивості ColorComboBoxItem

Ім'я Тип Опис
Content Bind Обов'язкова прив'язка. Властивість елементу масиву, яка виводиться як текст мітки.
Value Bind Обов'язкова прив'язка. Властивість елементу масиву, яка буде значенням списку.
Color Bind Обов'язкова прив'язка. Властивість елементу масиву з ім'ям кольору мітки (ті самі імена, що у ColorPicker).
Outline Boolean Показувати тільки обводку міток.

Опис

Статичний вміст не підтримується: список завжди будується з масиву ItemsSource.

Якщо Value списку прив'язано до об'єкта, при виборі йому присвоюється обраний елемент масиву. Інакше присвоюється значення властивості, заданої в Value елементу ColorComboBoxItem.

Клавіші ↑ і ↓ перебирають елементи без відкриття списку.
