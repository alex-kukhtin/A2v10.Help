Елемент Graphics

Всі елементи керування

Являє собою місце для відмальовки графіки. Сама відмальовка виконується програмно з використанням делегата.

Графіка малюється засобами бібліотеки d3.js. Сам файл d3.min.js постачається разом з платформою (папка wwwroot/scripts), але підключається він по-різному:

  • у версії .NET Framework бібліотека підключається автоматично і завжди - робити нічого не потрібно;
  • у версії .NET Core автоматичного підключення немає - скрипт потрібно підключити самостійно у файлі _scripts.html спеціальної папки _layout.

Якщо бібліотека не підключена, замість графіки елемент відобразить повідомлення про помилку.

Наслідує: UIElementBase

Властивості

Ім'я Тип Опис
Delegate String Ім'я делегата, який буде викликатися для відмальовки графіки. Обов'язкова властивість - якщо її не задано, при формуванні розмітки виникне помилка.
Argument Object Аргумент (зазвичай це прив'язка Bind), який буде передано в делегат.
CenterContent Boolean Чи центрувати вміст. Якщо true, вміст елемента центрується одночасно по горизонталі та по вертикалі. Має сенс тільки разом із заданою висотою (властивість Height).
Watch WatchMode Режим відслідковування змін при зміні значення аргумента. Можливі значення:
  • None - (за замовчуванням) не відслідковувати.
  • Watch - викликати делегат тільки при зміні аргумента.
  • Deep - викликати делегат при зміні аргумента або при зміні будь-яких його вкладених властивостей (рекурсивно).
Height Length Висота елементу. За замовчуванням Auto.
CssClass String Класи css, які потрібно додати до елементу. Може бути прив'язкою.
Властивості базового елементу

Формат делегата

draw(this:IRoot, chart:object, arg:any, node:DOMElement): void

Аргументи:

  • chart - вузол DOM, пов'язаний з елементом, "загорнутий" в об`єкт вибірки (selection) бібліотеки d3.js, тобто результат виклику d3.select(node).
  • arg - аргумент, описаний в розмітці.
  • node - вузол DOM, пов'язаний з елементом.

Перед кожним викликом делегата вміст елемента повністю очищується, тому делегат завжди малює графіку "з нуля" - дописати щось до попереднього результату не вийде.

Зверніть увагу! Зазвичай потрібно, щоб відмальовка графіки виконувалася однократно. Однак, в деяких випадках елемент, пов'язаний з графікою може змінюватися.
Встановити режим відслідковування змін можна за допомогою властивості Watch. Не встановлюйте режим Deep без необхідности, оскільки це призводить до зниження швидкодії.
