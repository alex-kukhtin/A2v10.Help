Елемент ColorPicker

Всі елементи керування

Являє собою вибір кольору зі спадного списку кольорових міток.

Наслідує: ValuedControl : Control : UIElement : UIElementBase

Властивості

Ім'я Тип Опис
Value Bind Ім'я обраного кольору (рядок). Можливі значення:
default green orange cyan red purple pink gold
blue salmon seagreen tan magenta lightgray olive teal
Text String Текст, який виводиться на мітках.
Compact Boolean Компактний вигляд елементу.
Властивості базового елементу

Опис

Клавіші ↑ і ↓ перебирають кольори без відкриття списку.
