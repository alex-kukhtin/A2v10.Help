Компонент Confirm

Всі компоненти

Підтвердження, яке користувач має дати перед виконанням команди. Задається властивістю Confirm прив'язки BindCmd; якщо користувач відмовився, команда не виконується.

Зазвичай досить тексту повідомлення: рядок у властивості Confirm стає значенням Message. Повна форма потрібна, лише щоб змінити заголовок або написи на кнопках.

Властивості

Ім'я Тип Опис
Message String За замовчуванням. Текст повідомлення.
Title String Заголовок вікна.
OkText String Напис на кнопці підтвердження.
CancelText String Напис на кнопці скасування.

Кожна властивість може бути прив'язкою (Bind). Значення, які не задано, беруться з локалізації - див. властивості об'єкта confirm.
